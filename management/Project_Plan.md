# Project Plan

Project Title: Development of an AI-powered chatbot for customer support

Project Type: Group Diploma Project

University: Astana IT University

Team: Balnur, Karina, Karakat

Project Manager: Karina Kargapoltseva

## 1. Project Goal

The goal of this project is to develop a configurable AI-powered customer support chatbot platform that allows multiple businesses to manage their own chatbot settings, knowledge bases, and customer interactions.

## 2. Team Responsibilities

- Balnur — Programmer / Developer: Backend development, frontend implementation, AI integration, database operations, testing, and deployment.
- Karina — Project Manager: Project planning, task coordination, YouTrack management, risk monitoring, documentation, and progress tracking.
- Karakat — System Analyst: Requirements analysis, literature review, system architecture, diagrams, API specifications, and evaluation planning.

## 3. Development Phases

Phase 1: Research and Requirements Analysis
- Prepare the Project Proposal.
- Review academic literature and existing chatbot systems.
- Define project scope and initial requirements.

Phase 2: System Architecture and Design
- Prepare System Context, Use Case, and Component diagrams.
- Design the database structure and API interactions.
- Prepare the initial UI prototype.

Phase 3: Frontend Development
- Develop registration and login pages.
- Create the business administration dashboard.
- Develop the customer chat interface.

Phase 4: Backend and Database Development
- Implement the Python backend and REST APIs.
- Develop authentication and business configuration management.
- Integrate the database.

Phase 5: AI Chatbot Integration
- Integrate the selected AI model.
- Implement business-specific knowledge retrieval.
- Develop chatbot response generation and fallback handling.

Phase 6: Additional Functionality
- Implement knowledge base management.
- Add conversation history.
- Implement human support escalation.

Phase 7: Testing and Evaluation
- Conduct functional and integration testing.
- Evaluate response accuracy and relevance.
- Test performance, security, and tenant data isolation.

Phase 8: Deployment and Documentation
- Deploy the completed system.
- Prepare technical documentation and user instructions.
- Complete the final diploma report and presentation.
